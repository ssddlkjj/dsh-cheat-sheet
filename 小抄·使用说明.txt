小抄 · 使用说明
（dsh-cheat-sheet · 0.2.0）

一句话：把一小段"每次都要记着"的话，塞进这条对话的每一轮里。
写在状态栏，随时开关、随时改。

先说容易踩的坑，再说怎么用、怎么跑、怎么改成你要的样子。


━━━━━━━━━━ 一、用前须知（先看这段）━━━━━━━━━

1. 它只管“当前这条对话”
   换一条对话就是另一个开关，新开的对话默认关着。

2. 默认是“聊天向”的一小段
   讲的是怎么说话像人：短句、不摆清单、有动作才带表情、报结果说三句。
   这是通用件，不认任何角色；想当纯工作说明用，看第四节。
   反过来说，聊天向也不是只能聊天——干活照样能用，只是语气没那么严肃。
   它管的是“怎么说”，不管“做没做对”；数字、路径、结论这些还是按你自己的规矩来。

3. 改的东西存在浏览器里
   开关和原文都存在这条对话自己的记录里（localStorage，键名 cheat.sheet.<会话 id>）。
   清缓存、换浏览器会丢；换对话不通用。

4. 打开之后下一轮才生效
   已经在生成的那一条不会带着它。

5. 原文太长了反而没用
   建议控制在 150 字以内。塞进系统提示的东西，越短越容易被遵守。

6. 它不改你的人格文件
   小抄只是每轮多一段提示；人设、状态、记忆该怎么写还怎么写。

7. 两个默认值要一致
   后台 index.js 和前端 client.js 里各有一份默认文本。要让“恢复默认”也变成你的版本，
   两处都要改，不然右键打开看到的还是旧的。


━━━━━━━━━━ 二、怎么用 ━━━━━━━━━━

【它显示在哪】
输入框下面那条状态栏——显示 tok/s、缓存命中率的那一行。
会多出一个按钮：

    小抄·停     关着
    小抄·开     开着

【左键】
点一下开，再点一下关。开的时候按钮旁会短暂显示“已开 · 装上了”或“已开 · 没装上”。

【右键】
弹出一个编辑窗，里面就是这段原文：

    · 直接改，Ctrl+Enter 保存（或点“保存”）
    · Esc 或点窗外取消
    · “恢复默认”把它退回出厂文本
    · 最多 600 字

【存哪】
开关和原文按对话存在浏览器里。同一条对话里改一次，之后每轮都带这段。

【它怎么影响回复】
每轮请求前，这段话会作为一段系统提示加进去。你在对话里看不到它，但角色会看见。


━━━━━━━━━━ 三、它是怎么跑的 ━━━━━━━━━━

1. 前端（client.js）
   画按钮和编辑窗；开关、原文一改就发给后台。

2. 后台（index.js）
   按会话记状态。开着的会话，在 agent 创建时往它的 systemPrompt 里注册一段
   （name: cheat-sheet:hint，order 9000）。
   关掉就撤掉这段注册；改原文就重装一次。

3. 为什么按会话注册
   DSH 的 systemPrompt 支持“只对某个 agent 生效”的分层，所以这段话不会漏到别的对话。
   默认关，就是为了不让它污染别人的会话。


━━━━━━━━━━ 四、三套现成写法（复制进右键窗口即可）━━━━━━━━━

【A · 模板：聊天＋干活（默认，先用这个）】
说话像人：短句，一句一行；不摆清单、不归纳成金句、不写承诺句。
奥卡姆剃刀：能删的多余先删，再动手。
干活时：数字、路径、结论一个字不改；报结果三句。
改或复述规则时，先照抄原文，再动，不凭记忆重写。

【B · 备选：只聊天】
说话像人：短句，一句一行；不摆清单、不归纳成金句、不写承诺句。
奥卡姆剃刀：能删的多余先删，再动手。
（你的角色如果有表情清单——颜文字、动作词那一类——自己再加一行：
 “有动作才带一只表情，单轮最多一只；写法照那清单。” 没有清单就别加。）

【C · 备选：只干活】
结论在前，数字、路径、命令一个字不改。
报结果三句：改了什么、现在什么样、你需要做什么。
不确定就说不确定，不猜、不编进度。
不写寒暄、不写承诺句、不摆清单。
改或复述规则时，先照抄原文，再动，不凭记忆重写。

装的时候默认就是 A。要换，右键粘 B 或 C，保存，开着就行。


━━━━━━━━━━ 五、装好之后可以做的一步（交给 AI）━━━━━━━━━

插件自带的是通用文本，不知道你的角色。想让小抄贴着你的人设走，把这段发给 AI：

    “我刚装了 dsh-cheat-sheet（小抄插件）。请帮我把默认小抄改成适合我角色的版本：
     说话习惯、表情密度、报结果的方式。控制在 150 字以内。
     顺便把 index.js 和 client.js 里的 DEFAULT_HINT 两处改成同一个文本。”

AI 要动的地方：

1. 右键窗口里的原文（只对当前对话生效），或者
2. DEFAULT_HINT（两处同改，变成所有新对话的默认）

改完刷新页面，新的一段才会用上。


━━━━━━━━━━ 六、装法 ━━━━━━━━━━

从 GitHub 拿的：仓库页点 Code → Download ZIP，解压，得到一个文件夹。
（不是 .zip 本身，要解压出来的那个目录。）

把整个文件夹放到稳定位置，然后在 DSH 里：

    plugin_manager
      action: install_bundle
      target: <这个文件夹的绝对路径>

装完重启一次（或刷新页面）。下一条对话打开时，状态栏会出现「小抄·停」。
